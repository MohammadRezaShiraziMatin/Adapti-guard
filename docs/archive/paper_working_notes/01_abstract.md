# Abstract

AdaptiGuard is a modular runtime defense and evaluation framework for prompt-injection and related LLM-agent attacks. It compares fixed and adaptive discrete intervention policies (L0–L3) under a shared security–utility–cost protocol, with a frozen attack stream for simulation and a real-LLM Target path for provider-backed evaluation. This release documents implemented mechanisms, reproducible artifacts, and explicit limitations where independent judging or multi-model evaluation was blocked by API constraints.
