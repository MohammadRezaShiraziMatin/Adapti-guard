Status: **baseline snapshot, not a result.** This document fixes the current state of the project so that the paper is written from a known, hash-checked starting point. It does not claim any defense works or fails.

## 1. Governing rules from this point

1. **Legacy information is not used for claims** unless the owner approves it case by case. See `LEGACY_CLAIMS.md`.
2. **Frozen artifacts are not edited.** `datasets/frozen/*`, `datasets/attackset_hard_v1/*`, `experiments/**/AUDIT*`, `results/**` are fixed. Any change creates a new versioned folder with its own hashes and a logged reason.
3. **Every number in the paper** must map to a file path and a metric key listed in `NUMBERS_LEDGER.md`, and the file must appear in `BASELINE_SHA256.txt` or in a later baseline.
4. **Pre-registration:** no external registration exists yet. The paper must not say the protocol was registered before a run. Local drafts are labelled as drafts.
5. **Models:** the current evidence uses `qwen/qwen-2.5-7b-instruct` (target) and `qwen/qwen-2.5-72b-instruct` (judge). These results are kept as a pilot. They are not evidence about strong models.
