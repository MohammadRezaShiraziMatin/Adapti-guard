## Phase 1: data readiness (cap 0.15)
| step | what | cost |
|---|---|---|

| 1b | Cross-channel and cross-goal items (calendar, web page, JSON tool output, file metadata; delete, share, update-setting, transfer) generated by a model family that is neither a target nor a judge, fixed hashed meta-prompts, then the same QC; 25% rated by the two humans | about 0.10 |
