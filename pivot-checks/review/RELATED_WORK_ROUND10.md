- **Bellibatlu, Wang, Zhang 2609.37315v1.** Executable-contract audit of *tools* (do mutating tools do what their interface advertises) in four benchmarks, including AgentDojo v1. 34 tools; 7 tool defects plus 1 evaluator property confirmed at pinned commits (Abstract; §V-B1). Gold-trajectory replay checks whether shipped reference paths reach the defects (§V-B2). **Not covered:** injection-task ground_truth() vs security(), and AgentDyn. *Overlap:* the closest work, auditing AgentDojo artifacts by execution at pinned commits. *Difference:* the layer audited (tool implementation vs reference solution vs security predicate).
- **BenchGuard 2604.24955.** LLM-based auditing of execution-based benchmarks. Its taxonomy has a GT category, "errors in the reference solution" (§3.2, Table 1). Applied to ScienceAgentBench and BIXBench (§5.1–5.2). *Overlap:* reference-solution defects as a named class. *Difference:* we audit deterministically, on an IPI benchmark.
